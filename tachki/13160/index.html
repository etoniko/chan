Skoda разрешила БЕСПЛАТНО печатать аксессуары для своих автомобилей на 3D-принтере — компания выложила готовые модели, разработанные собственными инженерами.

В коллекции есть подстаканники, держатели для смартфонов, органайзеры и крючки для проводов. Большинство аксессуаров подходят к штатным местам в салоне, поэтому ничего переделывать не придётся.

Про старые модели тоже не забыли: есть детали и для автомобилей, снятых с производства.
