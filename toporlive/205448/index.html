⚡️Путин на предстоящих переговорах по Украине, вероятно, потребует сократить присутствие НАТО в Европе до уровня 1997 года, — The Telegraph.

По информации издания, Россия попытается использовать новый раунд мирных переговоров по Украине, чтобы добиться уступок, ослабляющих оборону НАТО.

Среди возможных требований Москвы — вывод войск альянса из Польши, Эстонии, Латвии, Литвы и Финляндии, которая вступила в НАТО в 2023 году.
