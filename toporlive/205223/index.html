⚡️Путин поручил правительству РФ привлекать ветеранов СВО для обеспечения экономики квалифицированными кадрами по востребованным специальностям.

Другие поручения президента РФ:

— расширение применение технологий регенерации тканей при лечении ранений;

— предложения по стимулированию участия бизнеса в социальных инициативах;

— включение в атлас новых профессий специальностей в сфере обороны.
